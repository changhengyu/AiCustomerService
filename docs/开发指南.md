## 本地启动

### 一键启动（推荐）
```bash
# 准备环境变量
cp .env.example .env
# 编辑 .env，填入 TONGYI_API_KEY（必需）

# 启动
./start.sh        # Linux/macOS
start.bat         # Windows
```

启动后访问：
- API: http://localhost:5000
- Admin: http://localhost:5173
- MiniApp (H5): http://localhost:5174
- Hangfire: http://localhost:5000/hangfire

### 分步启动

#### 1. 启动数据库
```bash
docker compose up -d postgres redis
```

#### 2. 启动后端
```bash
cd backend/src/AiCustomerService.Api
dotnet run
```

#### 3. 启动 Admin
```bash
cd frontend/admin
npm install
npm run dev
```

#### 4. 启动 MiniApp
```bash
cd frontend/miniprogram
npm install
npm run dev:h5
```

## 后端开发

### 项目依赖关系
```
Api ──► Infrastructure ──► Core
                            ▲
Worker ──► Infrastructure ─┘
```

- **Core**：纯领域，无任何外部依赖（除 Pgvector 库用于向量类型）
- **Infrastructure**：实现 Core 的接口（EF Core、Redis、AI、WeChat 等）
- **Api**：Web 层，依赖注入 Controllers
- **Worker**：未来独立的 Worker 服务

### 添加一个新功能的标准流程

例：添加"客户标签管理"功能

#### 1. 在 Core 中定义接口
```csharp
// src/AiCustomerService.Core/Interfaces/ICustomerTagService.cs
public interface ICustomerTagService
{
    Task<List<TagDto>> ListAsync(Guid tenantId, CancellationToken ct);
    Task<TagDto> CreateAsync(Guid tenantId, string name, CancellationToken ct);
    Task DeleteAsync(Guid tenantId, Guid tagId, CancellationToken ct);
}
```

#### 2. 定义 DTO
```csharp
// src/AiCustomerService.Core/DTOs/Customer/TagDto.cs
public record TagDto(Guid Id, string Name, int UsageCount, DateTime CreatedAt);
```

#### 3. 在 Infrastructure 中实现
```csharp
// src/AiCustomerService.Infrastructure/Services/CustomerTagService.cs
public class CustomerTagService : ICustomerTagService
{
    private readonly AppDbContext _db;
    public CustomerTagService(AppDbContext db) { _db = db; }

    public async Task<List<TagDto>> ListAsync(Guid tenantId, CancellationToken ct)
    {
        return await _db.CustomerTags
            .Where(t => t.TenantId == tenantId)
            .Select(t => new TagDto(t.Id, t.Name, t.UsageCount, t.CreatedAt))
            .ToListAsync(ct);
    }
    // ...
}
```

#### 4. 注册到 DI
```csharp
// src/AiCustomerService.Infrastructure/DependencyInjection.cs
services.AddScoped<ICustomerTagService, CustomerTagService>();
```

#### 5. 在 Api 中创建 Controller
```csharp
[ApiController]
[Route("api/v1/customer-tags")]
[Authorize]
public class CustomerTagController : ControllerBase
{
    private readonly ICustomerTagService _service;
    private readonly ITenantContext _tenantCtx;
    // ... 注入

    [HttpGet]
    public async Task<ActionResult<List<TagDto>>> List(CancellationToken ct)
    {
        return Ok(await _service.ListAsync(_tenantCtx.RequireTenantId(), ct));
    }
}
```

## 前端开发

### Admin（Vue 3）

技术栈：Vue 3 Composition API + Vite 5 + Element Plus + Pinia + Axios

#### 新增一个页面
1. 在 `src/views/` 下创建 `NewPage.vue`
2. 在 `src/router/index.ts` 添加路由
3. 在 `Layout.vue` 侧边栏添加导航
4. 在 `src/api/index.ts` 添加对应 API 方法
5. 在 `src/stores/` 添加状态（如果需要）

#### API 客户端使用
```typescript
import { customerApi } from '@/api';

const detail = await customerApi.detail(id);
```

#### HTTP 拦截器
- 自动注入 JWT Token
- 401 自动登出

### MiniApp（uni-app）

技术栈：uni-app 3.x + Vue 3 + Pinia

#### 跨端编译
```bash
# H5
npm run dev:h5

# 微信小程序
npm run dev:mp-weixin

# APP
npm run dev:app
```

#### 条件编译
```vue
<!-- #ifdef H5 -->
<view>H5 专属</view>
<!-- #endif -->

<!-- #ifdef MP-WEIXIN -->
<view>微信小程序专属</view>
<!-- #endif -->
```

#### 主题
所有页面统一使用 `src/style/theme.scss` 中定义的设计令牌（颜色、圆角、阴影、字体）。

## 数据库迁移

### 创建迁移
```bash
cd backend/src/AiCustomerService.Infrastructure
dotnet ef migrations add MigrationName \
  --startup-project ../AiCustomerService.Api
```

### 应用迁移（自动）
开发环境启动时自动执行 `db.Database.Migrate()`。

### 手动应用
```bash
dotnet ef database update \
  --startup-project ../AiCustomerService.Api
```

### 回滚
```bash
dotnet ef migrations remove \
  --startup-project ../AiCustomerService.Api
```

### 生产环境
生产环境**不要**用 Migrate，建议使用：
```bash
dotnet ef migrations script \
  --startup-project ../AiCustomerService.Api \
  --idempotent \
  -o migrations.sql
```
然后 DBA 审核后手动执行。

## 代码规范

### C#

- 使用 C# 12+ 新语法（file-scoped namespace、record 类型、模式匹配）
- 异步方法命名以 `Async` 结尾
- 控制器方法必须返回 `ActionResult<T>`
- 业务异常使用 `BusinessException` 子类
- 强制 nullable：所有引用类型必须明确标注 `?` 或确定非空

### TypeScript / Vue

- 使用 Composition API + `<script setup>`
- Props 类型用 `defineProps<{}>()`
- 组件名采用 PascalCase
- 文件名采用 PascalCase（页面）或 camelCase（工具）
- 禁止使用 `any`（必要时用 `unknown`）

### SCSS

- 使用设计令牌（CSS 变量），不要硬编码颜色
- 嵌套不超过 3 层
- 类名采用 BEM 或 utility-first

## Git 提交规范

采用 Conventional Commits 规范：

```
<type>(<scope>): <subject>

<body>

<footer>
```

### Type 类型
- `feat`：新功能
- `fix`：Bug 修复
- `refactor`：重构（既不是 feat 也不是 fix）
- `docs`：仅文档变更
- `style`：代码格式（不影响功能）
- `test`：添加或修改测试
- `chore`：构建工具、依赖变更
- `perf`：性能优化

### 示例
```bash
feat(knowledge): add PDF parsing for DocumentLoader
fix(auth): handle null tenant in refresh token flow
docs: update API documentation
refactor(ai): extract embedding retry logic
```

### 分支策略
- `main`：稳定分支，发布版本
- `feat/xxx`：功能分支
- `fix/xxx`：Bug 修复分支

PR 必须通过 CI 编译（`dotnet build` + `npm run build`）才能合并。
